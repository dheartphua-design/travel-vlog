# 雨霖之旅

Homepage for a travel vlog: the latest episode, a filterable episode archive, a route ledger of every leg travelled, and an about section.

It's a single static file, `index.html`, with no build step. Open it in a browser to preview.

## Editing content

Episodes and travel legs live in the `EPISODES` and `LEGS` lists inside the `<script>` near the bottom of `index.html`. The current entries are placeholder examples.

## Hosting

Served with GitHub Pages from the `main` branch.
